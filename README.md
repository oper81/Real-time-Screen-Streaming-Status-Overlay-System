# Real-time Screen Streaming & Status Overlay System

Учебный проект, демонстрирующий реализацию системы удаленного мониторинга и ассистирования на платформе Android с использованием асинхронного управляющего сервера на Python (FastAPI).

## 🚀 Архитектура системы

Система разделена на три ключевых компонента:
1. **Android Client (Kotlin)**: Фоновый сервис (`Foreground Service`), работающий параллельно в комбинированном режиме (`dataSync|mediaProjection`). Перехватывает кадры экрана через `ImageReader`, сжимает их в JPEG и транслирует бинарный поток по WebSocket. Одновременно с этим создает прозрачный для кликов текстовый оверлей (`SYSTEM_ALERT_WINDOW`) в статус-баре для вывода статус-кодов.
2. **FastAPI Backend (Python)**: Асинхронный сервер, обеспечивающий двусторонний обмен данными между смартфоном и панелью управления в реальном времени. В бэкенд встроен веб-сервер для отдачи интерфейса.
3. **Web Controller (HTML5/JS)**: Двухпанельный интерфейс напарника, отображающий живой стрим экрана смартфона (через генерацию `Blob` из байтового потока сокета) и форму отправки управляющих JSON-пакетов.

## 🛠️ Развертывание серверной части (Windows / Linux)

### 1. Установка зависимостей
Для работы сервера необходимы асинхронные библиотеки Python. Установите их через pip:

pip install fastapi uvicorn websockets pydantic


### 2. Редактирование файлов
В файле MainActivity.kt замените "const val WEBSOCKET_URL = "wss://YOUR-DOMAIN/ws?role=device""
 

### 2. Запуск локального сервера
Запустите основной файл сервера:

python server.py

Сервер начнет слушать входящие подключения на порту `8000` по адресу `http://0.0.0.0`.

### 3. Проброс в глобальный интернет через Ngrok
Если управляющий ПК и Android-устройство находятся в разных сетях (работа на расстоянии через LTE), пробросьте порт с использованием статического домена Ngrok:

ngrok http 8000 --url=YOUR_STATIC_DOMAIN.ngrok-free.dev

## 📱 Сборка Android-клиента (VS Code / Gradle CLI)

Сборка приложения оптимизирована для ручной компиляции в терминале без использования Android Studio. Требуется установленный **JDK 17** или **JDK 21**.

### Команда для компиляции отладочного APK на Windows:

\$env:JAVA_HOME="C:\Users\YOUR_USERNAME\.jdks\jbr-21.0.11"
cmd /c "gradle.bat assembleDebug -Dorg.gradle.java.home='C:\Users\YOUR_USERNAME\.jdks\jbr-21.0.11'"


Готовый установщик будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`

## 📦 Инструкция по тестированию (Симуляция)

1. Установите полученный APK-файл на целевой Android-смартфон.
2. В настройках телефона (особенно на оболочках MIUI / HyperOS) перейдите в свойства приложения и принудительно включите разрешение **«Отображать всплывающие окна при работе в фоновом режиме»**.
3. Запустите `server.py` и `ngrok`.
4. Откройте в браузере напарника адрес панели управления: `https://YOUR_STATIC_DOMAIN.ngrok-free.dev/`. Убедитесь, что индикатор WebSocket горит зеленым.
5. Запустите приложение на телефоне, предоставьте права на оверлей и подтвердите системный запрос на захват экрана.
6. Переведите тестируемое приложение в режим закрепления экрана (**App Pinning**), чтобы сымитировать жесткие условия экзамена. 
7. Проверьте задержку ввода статус-кодов и плавность отображения графического потока в браузере контроллера.
